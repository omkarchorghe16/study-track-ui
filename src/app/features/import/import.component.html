CSV format

Column 1 is the question, column 2 the answer, and an optional column 3 the topic (use > for subtopics). A first row such as question,answer,topic is skipped. Rows without a topic go to a topic named after the file. Save from Excel or Google Sheets as CSV UTF-8. No LLM is used. Rows that repeat a question already in the subject are skipped.

question,answer,topic
